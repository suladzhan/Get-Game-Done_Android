# Project-specific docs

Copy the templates from `../templates/` into this folder when adopting the framework in a real game project.

Recommended files:

- `GAME_DESIGN.md`
- `ROADMAP.md`
- `ART_DIRECTION.md`
- `ASSET_REQUIREMENTS.md`
- `ASSET_REGISTER.md`
- `QA_CHECKLIST.md`
- `RELEASE_CHECKLIST.md`

Keep `PROJECT_STATE.md` at the repository root so agents can discover it quickly.
