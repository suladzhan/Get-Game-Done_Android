# Contributing

Contributions are welcome.

Good contributions make the framework more reproducible, engine-aware, measurable, and tool-neutral.

When proposing a new agent or skill:

- keep responsibilities narrow
- state required inputs and outputs
- define validation checks
- define stop/escalation conditions
- avoid vendor lock-in unless the contribution is explicitly an adapter
- do not include proprietary prompts, copyrighted asset packs, credentials, or paid content

For major changes, open an issue describing the workflow problem before submitting a large rewrite.
