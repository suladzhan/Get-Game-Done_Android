# Skill: Art Direction

## Purpose

Define a coherent, achievable visual language before asset replacement.

## Use when

The active pipeline stage assigns this skill, or the Orchestrator explicitly invokes it to resolve a blocker.

## Required inputs

- Game design
- Current screenshots/assets

## Procedure

1. Define target visual style, mood, shape language, typography, icon language, UI density, animation feel, and technical constraints.
2. Create a small reference board or written references without copying protected art.
3. Inventory current placeholders and group required assets by priority.
4. Define consistency rules so unrelated asset packs do not create a visual collage.
5. Write ASSET_REQUIREMENTS.md before large-scale asset acquisition.

## Outputs

- docs/ART_DIRECTION.md
- docs/ASSET_REQUIREMENTS.md

## Validation checklist

- [ ] Style rules are explicit
- [ ] Asset gaps are prioritized

## Stop / escalate when

Stop and report to the Orchestrator when required inputs are missing, the task would cross an approval gate, the requested change conflicts with approved design, or validation cannot be performed reliably.
