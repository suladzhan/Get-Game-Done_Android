# Skill: Game Design

## Purpose

Convert an idea into an implementable game design.

## Use when

The active pipeline stage assigns this skill, or the Orchestrator explicitly invokes it to resolve a blocker.

## Required inputs

- Game concept
- Target audience/platform

## Procedure

1. Define player fantasy, core loop, controls, session length, success/failure states, and difficulty model.
2. Define progression, rewards, unlocks, content categories, and retention features only when they support the core loop.
3. Define explicit non-goals to prevent scope creep.
4. Document monetization assumptions separately from core fun.
5. Define measurable prototype questions: what must be proven before expansion?

## Outputs

- docs/GAME_DESIGN.md
- docs/ROADMAP.md

## Validation checklist

- [ ] Engineer can prototype without inventing core rules
- [ ] Scope and non-goals are explicit

## Stop / escalate when

Stop and report to the Orchestrator when required inputs are missing, the task would cross an approval gate, the requested change conflicts with approved design, or validation cannot be performed reliably.
