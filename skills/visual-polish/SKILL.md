# Skill: Visual Polish

## Purpose

Improve game feel after mechanics/content are stable.

## Use when

The active pipeline stage assigns this skill, or the Orchestrator explicitly invokes it to resolve a blocker.

## Required inputs

- Stable gameplay
- Art direction
- Approved assets

## Procedure

1. Replace placeholders systematically by screen/system.
2. Improve hierarchy, spacing, readability, motion timing, transitions, VFX, camera response, and reward feedback.
3. Use animation to communicate state, not only decoration.
4. Keep effects interruptible and avoid blocking input unnecessarily.
5. Check visual clarity at gameplay speed and on mobile-sized screens.
6. Regression-test gameplay after polish; do not bury logic changes inside presentation work.

## Outputs

- Polished screens/gameplay feedback

## Validation checklist

- [ ] Core actions are visually clear
- [ ] No placeholder remains without reason
- [ ] Gameplay behavior unchanged except approved fixes

## Stop / escalate when

Stop and report to the Orchestrator when required inputs are missing, the task would cross an approval gate, the requested change conflicts with approved design, or validation cannot be performed reliably.
