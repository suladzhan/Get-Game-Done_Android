# Release Checklist

## Build

- [ ] Version code/name updated
- [ ] Release AAB builds successfully
- [ ] Correct package identifier
- [ ] Correct signing configuration
- [ ] Signing secrets are not in Git
- [ ] Release build smoke-tested

## Product

- [ ] No blocker/critical defect open
- [ ] Save/update path tested
- [ ] Analytics production configuration reviewed
- [ ] Monetization production configuration reviewed and human-approved
- [ ] Privacy behavior reviewed

## Google Play materials

- [ ] App name/description
- [ ] App icon
- [ ] Screenshots / graphics
- [ ] Privacy policy (if applicable)
- [ ] Content rating inputs
- [ ] Data safety declarations based on actual SDK/data behavior
- [ ] Ads declaration
- [ ] App access instructions if required
- [ ] Release notes

## Rollout

- [ ] Internal/closed testing completed
- [ ] Crash/ANR check reviewed
- [ ] Rollback plan documented
- [ ] Human production-publish approval recorded
